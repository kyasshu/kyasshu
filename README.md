# 小川慶介 / Keisuke Ogawa

研究支援アプリの概要と、公開中のWebゲーム集をまとめています。

## 研究支援アプリ

本研究室で運用している研究支援アプリです。研究計画、シミュレーション、文献、装置マニュアルなどを用途別に整理しています。

研究室内で運用しているため、外部公開URLは掲載していません。

## Webゲーム集

ブラウザで動作する6作品をまとめています。

- 数学クイズラン
- ジャンプリズム
- 電場コネクト
- 四色記憶
- スターショット・サバイバーズ
- ころころ工場
