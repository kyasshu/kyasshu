# 小川慶介 / Keisuke Ogawa

研究支援アプリの公開デモと、Webゲーム集をまとめています。

## 研究支援アプリ

本研究室で運用している研究支援アプリです。研究計画、シミュレーション、文献、装置マニュアル、研究日誌を用途別に整理しています。

公開デモは架空のサンプルデータだけを使用し、会社・研究室のサーバーや本番データには接続しません。

- **[研究支援アプリの公開デモ](https://kyasshu-portfolio.kyasshu.chatgpt.site/research-demo)**
