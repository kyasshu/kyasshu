# 小川慶介 / Keisuke Ogawa

研究支援アプリの公開デモと、Webゲーム集をまとめています。

## 研究支援アプリ

研究活動向けに設計・運用している支援アプリです。研究計画、条件比較、資料整理、確認手順、作業記録を用途別にまとめています。

公開デモは名称・数値・記録を含めてすべて架空です。外部サーバーや本番データには接続しません。

- **[研究支援アプリの公開デモ](https://kyasshu-portfolio.kyasshu.chatgpt.site/research-demo)**
