# 小川慶介 / Keisuke Ogawa

研究室で運用する研究支援アプリと、ブラウザで動くインタラクティブ作品を制作しています。

## 公開しているもの

公開作品は **[研究支援アプリ](https://github.com/kyasshu/nv-dft-viewer)** にまとめています。  
本研究室で運用している、研究活動に必要な情報とツールを目的別に選べるアプリです。材料研究だけに限定せず、研究計画、シミュレーション、文献、装置マニュアル、ミニゲームをまとめています。

```text
研究支援アプリ
├─ 研究計画
│  └─ 目的、仮説、検証の流れを整理
├─ シミュレーション
│  ├─ DFT / NEB：結晶再構成
│  ├─ PIC-MCC：電子照射輸送
│  └─ Rate model：NV形成量
├─ 参考文献
│  └─ 研究の根拠となる資料
├─ 装置操作マニュアル
│  └─ 実験装置の操作手順
└─ ミニゲーム集
   └─ JavaScript、Canvas、Three.jsの6作品
```

## 初めて見る方へ

1. **[研究支援アプリを開く](https://kyasshu.github.io/nv-dft-viewer/)**  
   最初の画面から「用途別メニュー」を開きます。

2. **見たい用途を選ぶ**  
   研究計画、シミュレーション、参考文献、装置マニュアル、ミニゲームに分かれています。

3. **[ソースコードとREADMEを見る](https://github.com/kyasshu/nv-dft-viewer)**  
   実装内容、研究上の前提、ファイル構成、実行方法を確認できます。

## 主な技術

- Research: DFT / NEB、Quantum ESPRESSO、PIC-MCC、形成量モデル
- Programming: Python、JavaScript
- Web: HTML、CSS、Canvas API、Three.js、WebGL
- Delivery: GitHub Pages、静的Webアプリ
