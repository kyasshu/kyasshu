# 小川慶介 

研究支援アプリのデモ版と、Webゲーム集をまとめています。

## 研究支援アプリ

所属研究室における日々の研究活動を支援するために、設計・開発したWebアプリです。

研究記録やタスク、参考文献、装置の操作方法など、研究室内に分散しやすい情報を一か所にまとめ、メンバー間で共有・更新できるようにしています。

公開しているデモ版は実際の運用サーバーには接続していません。  
研究室内の情報を含まないサンプルデータを使用し、一部の機能を制限した状態で公開しています。

### 主な機能

- 研究日誌とタスクの記録・管理
- 参考文献の整理・共有
- 装置操作マニュアルの閲覧とコメント
- 研究用シミュレーションツール
- 学習要素を取り入れたミニゲーム集

### 設計の考え方

アイドルゲームをモチーフに、研究室の学生が毎日親しみを持って利用できるデザインを目指しました。

実運用版ではサーバーを介して、各メンバーが情報やコメントを書き込めます。研究記録や装置の改善点、操作上の注意などを継続的に蓄積し、研究室全体でノウハウを共有できる仕組みにしています。
