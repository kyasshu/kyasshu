# 小川慶介 

研究支援アプリのデモ版と、Webゲーム集をまとめています。

## 研究支援アプリ

本研究室での研究活動向けに設計・運用している支援アプリです。
デモ版ではサーバーには接続せず、公開できる情報に絞って公開しており、一部機能も制限しています。

機能一覧
・研究日誌、タスク管理
・参考文献まとめ
・装置操作マニュアル
・シミュレーションソフト
・学べる・遊べるミニゲーム集

設計思想
・アイドルゲームをモチーフに、研究室の学生達が毎日研究に取り組めるよう親しみやすい作りを目指しています。
・動的サーバーを使用して、各メンバーが書き込み、改善ノウハウを蓄積できる仕組みを構築しています。


- **[研究支援アプリのデモ版](https://kyasshu-portfolio.kyasshu.chatgpt.site/research-demo)**
