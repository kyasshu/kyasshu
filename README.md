# 小川慶介 / Keisuke Ogawa

研究室で運用する研究支援アプリと、ブラウザで動くインタラクティブ作品を制作しています。

## 公開している代表作品

### 1. 研究支援アプリ

本研究室で運用している、研究活動に必要な情報とツールを目的別に選べるアプリです。材料研究だけに限定せず、研究計画、シミュレーション、文献、装置マニュアルをまとめています。

- **[アプリを開く](https://kyasshu.github.io/nv-dft-viewer/)**
- **[ソースコードとREADME](https://github.com/kyasshu/nv-dft-viewer)**

```text
研究支援アプリ
├─ 研究計画
│  └─ 目的、仮説、検証の流れを整理
├─ シミュレーション
│  ├─ DFT / NEB：結晶再構成
│  ├─ PIC-MCC：電子照射輸送
│  └─ Rate model：NV形成量
├─ 参考文献
│  └─ 研究の根拠となる資料
└─ 装置操作マニュアル
   └─ 実験装置の操作手順
```

### 2. Webゲーム作品集

インストール不要で、PCとスマートフォンからすぐ遊べる6作品をまとめています。

- 数学クイズラン
- ジャンプリズム
- 電場コネクト
- 四色記憶
- スターショット・サバイバーズ
- ころころ工場

- **[ゲーム作品集を開く](https://kyasshu.github.io/web-game-collection/)**
- **[ソースコードとREADME](https://github.com/kyasshu/web-game-collection)**

## 初めて見る方へ

研究・計算・資料管理の構成を見る場合は「研究支援アプリ」、UI・ゲーム実装を見る場合は「Webゲーム作品集」を開いてください。各リポジトリのREADMEに、目的、構成、使用技術をまとめています。

## 主な技術

- Research: DFT / NEB、Quantum ESPRESSO、PIC-MCC、形成量モデル
- Programming: Python、JavaScript
- Web: HTML、CSS、Canvas API、Three.js、WebGL
- Delivery: GitHub Pages、静的Webアプリ
